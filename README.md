# DR2C-Savediter
Death Road to Canada 存档编辑器：在英文原版与简体中文汉化版之间安全转换存档，支持 .slot / gstats、活动存档和自建角色编辑、物资/武器/属性修改、全局升级管理与自动备份。大部分代码由人工智能模型生成。
