DR2C 存档助手（Python 版）

当前版本：1.0.0
版本代号：旅途启程

兼容性
--------
已测试原版游戏版本：20260727
已测试简体中文汉化补丁版本：906.2
其他游戏、补丁或 Mod 版本未经测试，不保证能够使用。

武器 ID 规则
------------
武器资料 JSON 中保存的是英文原版的正式运行时 ID，来源为英文 weapondef
及其子文件的实际注册顺序。不要使用 Wiki 页面中写出的旧 ID。

当前汉化补丁 906.2 的规则：
- 英文存档 -> 中文存档：非零武器 ID + 1
- 中文存档 -> 英文存档：非零武器 ID - 1
- 0 表示空装备栏，始终保持 0，不参与偏移。

偏移必须由程序在转换时按补丁版本现场计算，不能预先写死到 JSON。
如果未来汉化补丁修复了编号偏移，应把该版本的偏移配置改为 0。

存档安全
--------
活动存档不是纯 UTF-8 文本，内部混有游戏控制字节。必须以二进制方式定点修改，
不得将整份活动存档 decode("utf-8") 后重新 encode，也不得用普通文本编辑器保存。
软件应在自身 backups 文件夹创建备份；不要在游戏运行时覆盖存档。

公开发布
--------
发布包不得包含 0.save、1.save、2.save、0mod.save 等活动存档，也不得包含真实的
自建角色存档、Windows 用户名、AppData 绝对路径或其他个人信息。
