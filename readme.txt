DR2C 存档助手（Python 版）

当前版本：1.0.2
版本代号：时光机

兼容性
--------
已测试原版游戏版本：20260727
已测试简体中文汉化补丁版本：906.2
其他游戏、补丁或 Mod 版本未经测试，不保证能够使用。

武器 ID 规则
------------
武器资料 JSON 中保存的是英文原版的正式运行时 ID，来源为英文 weapondef
及其子文件的实际注册顺序。不要使用 Wiki 页面中写出的旧 ID。

当前汉化补丁 906.2 的规则：
- 英文存档 -> 中文存档：非零武器 ID + 1
- 中文存档 -> 英文存档：非零武器 ID - 1
- 0 表示空装备栏，始终保持 0，不参与偏移。

偏移必须由程序在转换时按补丁版本现场计算，不能预先写死到 JSON。
如果未来汉化补丁修复了编号偏移，应把该版本的偏移配置改为 0。

存档安全
--------
活动存档不是纯 UTF-8 文本，内部混有游戏控制字节。必须以二进制方式定点修改，
不得将整份活动存档 decode("utf-8") 后重新 encode，也不得用普通文本编辑器保存。
软件应在自身 backups 文件夹创建备份；不要在游戏运行时覆盖存档。

活动存档跨语言转换
--------------------
英文和中文存档的地区／路途随机事件牌堆中，含有已本地化的 Forth 词标识与富文本
控制码，不能原样迁移。程序会删除这些已保存的牌堆赋值，让目标语言版本在读取时使用
自身已初始化的默认牌堆；否则 Forth 会在区域状态处中止读取，后面的天数、游戏模式等
字段也会回落为默认值。

不会重置：角色、物资、车辆、剩余天数、游戏模式和当前主流程 road-stack。
会发生的代价：后续随机事件牌堆重新生成，少量已经见过的事件可能再次出现。
该处理对英文 -> 中文、中文 -> 英文两个方向都生效。逐项无损保留牌堆顺序尚未实现，
后续方案见 TODO.md。

全局升级存档前向兼容
----------------------
旧版 gstats 的字段是新版 gstats 字段子集时，程序以目标新版文件为模板：复制所有同名
字段的旧进度，并把新版独有数值字段设为 0。例如旧版不存在的新游戏模式会显示为未通关，
不会继承目标模板已有的通关次数。来源存在目标没有的字段时，程序会拒绝反向降级转换。

公开发布
--------
发布包不得包含 0.save、1.save、2.save、0mod.save 等活动存档，也不得包含真实的
自建角色存档、Windows 用户名、AppData 绝对路径或其他个人信息。
